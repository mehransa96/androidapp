# هانیتا (Hanita)

اپلیکیشن اندروید برای پیش‌بینی قاعدگی، یادآوری زمان آن و ارائه راهنمایی‌های مناسب هر فاز چرخه (قبل، حین و بعد از قاعدگی).

## قابلیت‌ها
- ثبت روزهای خونریزی، علائم، حال، آب، وزن و دمای پایه بدن
- پیش‌بینی قاعدگی بعدی بر اساس میانگین ۶ چرخه آخر، تشخیص تأخیر و نامنظمی چرخه
- تخمین پنجره باروری، تخمک‌گذاری و PMS متناسب با طول واقعی چرخه هر کاربر
- یادآور قبل از قاعدگی، تخمک‌گذاری، شروع هر فاز و داروها (بعد از ریستارت گوشی و تغییر ساعت هم دوباره تنظیم می‌شوند)
- دستیار هوشمند و نکات روزانه هر فاز با Gemini (فقط با رضایت صریح کاربر)
- ثبت‌نام محلی در اولین اجرا (بدون فایربیس، ایمیل یا اینترنت) و قفل اختیاری با رمز، اثر انگشت و کد بازیابی
- پشتیبان خودکار رمزنگاری‌شده روزانه، فایل پشتیبان رمزدار و انتقال به گوشی جدید

## حساب کاربری و ذخیره‌سازی داده‌ها
- **بدون سرور:** حساب کاربری در اولین اجرا فقط روی گوشی ساخته می‌شود. Firebase Auth و Firestore حذف شده‌اند.
- همه سوابق در پایگاه داده Room و تنظیمات در SharedPreferences، داخل حافظه خصوصی برنامه ذخیره می‌شوند (sandbox اندروید + رمزنگاری فایل‌محور گوشی).
- **بدون پاک شدن در به‌روزرسانی:** هر تغییر ساختار پایگاه داده یک Migration دارد و حذف مخرب داده فقط برای نسخه پیش‌انتشار ۱ مجاز است. برای هر نسخه schema در `app/schemas` ثبت می‌شود.
- **نسخه امن خودکار:** هر روز (و هنگام رفتن برنامه به پس‌زمینه، حداکثر هر ۳ ساعت) یک کپی کامل با AES-256-GCM و کلید Android Keystore در حافظه خصوصی ذخیره می‌شود؛ ۷ روز آخر و کامل‌ترین نسخه نگه داشته می‌شوند. اگر پایگاه داده خالی پیدا شود، برنامه بازیابی را پیشنهاد می‌دهد.
- **فایل پشتیبان رمزدار:** از صفحه «حریم خصوصی و پشتیبان» با رمز دلخواه (PBKDF2 + AES-256-GCM) برای انتقال به گوشی جدید؛ در صفحه ثبت‌نام هم می‌توان از آن بازیابی کرد.
- **بکاپ اندروید:** پایگاه داده و تنظیمات فقط وقتی به بکاپ گوگل می‌روند که آن بکاپ با قفل صفحه گوشی رمزنگاری سرتاسری شده باشد؛ انتقال مستقیم به گوشی جدید هم پشتیبانی می‌شود.
- **قفل برنامه:** رمز ۴ تا ۶ رقمی (فقط هش PBKDF2 ذخیره می‌شود)، اثر انگشت، و کد بازیابی ۱۲ حرفی برای وقتی رمز فراموش شود.

## امنیت و حریم خصوصی
- **هیچ کلید API داخل اپ نیست.** هوش مصنوعی (اختیاری) از طریق Firebase AI Logic صدا زده می‌شود و Firebase App Check از آن محافظت می‌کند. این تنها استفاده از Firebase است.
- اعلان‌ها روی صفحه قفل محتوای حساس را نشان نمی‌دهند.
- فقط اتصال HTTPS مجاز است. نسخه release با R8 کوچک و مبهم‌سازی می‌شود.
- امضای release فقط از متغیرهای محیطی خوانده می‌شود و هیچ keystore یا رمزی در ریپو نیست.

## راه‌اندازی
1. پروژه را در Android Studio باز کنید (JDK 21).
2. **بدون Firebase:** اپ کامل بیلد و اجرا می‌شود: ثبت‌نام، ثبت روزانه، پیش‌بینی، یادآورها و پشتیبان‌گیری همه آفلاین کار می‌کنند؛ فقط هوش مصنوعی غیرفعال است.
3. **برای فعال کردن هوش مصنوعی (اختیاری):**
   1. در کنسول Firebase یک اپ اندروید با شناسه `com.aistudio.hanita.zxwpm` بسازید و `google-services.json` را در پوشه `app/` بگذارید (این فایل در git ثبت نمی‌شود).
   2. Firebase AI Logic را با Gemini Developer API فعال کنید.
   3. App Check را با Play Integrity فعال کنید. برای بیلد debug توکن دیباگی را که در Logcat چاپ می‌شود در کنسول ثبت کنید. بعد از آزمایش، اجبار (Enforce) را برای AI Logic روشن کنید.
4. بیلد release امضاشده:
   ```bash
   export KEYSTORE_PATH=/path/upload.jks STORE_PASSWORD=... KEY_ALIAS=upload KEY_PASSWORD=...
   ./gradlew assembleRelease
   ```

## تست
```bash
./gradlew testDebugUnitTest
```
منطق پیش‌بینی در `domain/CyclePredictor.kt` است و تست‌های آن در `app/src/test/java/com/example/CyclePredictorTest.kt` قرار دارند.

> هانیتا ابزار آگاهی از سلامت است و جایگزین نظر پزشک یا روش پیشگیری از بارداری نیست.
